## Visual system

- Deep background: `#07110D`
- Neon Matrix Green: `#39FF14`
- Functional green: `#00FF88`
- Circuit green: `#1DBF73`
- Ivory: `#F4F1E8`
- Silver: `#BFC9CA`
- Muted neutral: `#8D9690`

Preferred type families:
- Space Grotesk for display/headings
- Inter for UI/body
- IBM Plex Mono for system labels, metrics and technical text

System fonts remain valid fallbacks so the workout UI stays fast and robust.

## Official emblem

The De-Omega-Point emblem is a **locked master asset**.

It must not be redrawn, approximated, recoloured, stretched, rotated, blurred, stylised, cropped into a different mark or recreated with CSS/SVG primitives.

The approved emblem is the neon-green Omega/head/circuit mark with its full outer circle on a dark green/black background.

**Do not substitute a generic Omega symbol.**

The logo is intentionally not fabricated in this repository until the exact approved master binary is supplied.

When the master asset is added, place approved web exports under `assets/brand/` and reference that exact file from Client, Trainer and Administrator shells.

## Human-value behaviour

Branding is not only visual. Product behaviour should preserve:

- human agency
- Trainer responsibility for coaching decisions
- clear Administrator stewardship
- AI as assistance rather than autonomous authority
- privacy-conscious collection of client data
- understandable, reversible actions where practical
